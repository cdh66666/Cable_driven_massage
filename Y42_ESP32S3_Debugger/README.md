# Y42 四电机绳驱按摩设备调试固件

这是绳驱按摩设备的 ZDT Y42 第二代闭环步进电机版本。ESP32-S3 通过 RS485 控制四台电机，并直接提供中文手机测试页面、四角自动校准、内置图形和连续手绘轨迹。

当前版本已于 2026-08-03 在 ESP32-S3、CH343 `COM55` 和四台 Y42 X 固件电机上完成编译、烧录及热点启动验证。

## 已实现功能

- 无密码热点 `Y42-Debug`，手机连接后由 captive portal 自动打开测试页。
- 四台电机地址固定为 1、2、3、4，支持统一使能、失能和急停。
- 四角自动校准，自动计算并保存四台电机的绳长换算系数。
- 实时读取位置、转速、电流、温度和保护状态。
- 绘制大范围圆形、三角形和手机手绘轨迹。
- 手绘轨迹去抖、圆角和平滑连续控制。
- 气泵、放气泵和阀门网页控制。
- 校准参数和有效系数保存在 ESP32 NVS 中。

## 硬件连接

| ESP32-S3 | TTL 转 RS485 | 说明 |
|---|---|---|
| GPIO16 TX | RX / RXD | ESP32 向总线发送 |
| GPIO17 RX | TX / TXD | ESP32 接收总线数据 |
| 3.3V | VCC | 以模块实际电压要求为准 |
| GND | GND | 必须与电机电源共地 |
| - | A | 接 Y42 A/R/H |
| - | B | 接 Y42 B/T/L |

其他输出：

- GPIO47：充气泵。
- GPIO48：放气泵。
- GPIO45：放气阀门。
- 当前按高电平有效编写；低电平继电器需要对调 `ACTUATOR_ON` 和 `ACTUATOR_OFF`。

电机使用独立的 10-29V 动力电源，不得由 ESP32 USB 或 5V 引脚供电。ESP32 GPIO 不耐 5V，RS485 模块的串口侧必须兼容 3.3V。

## 编译与烧录

安装 PlatformIO 后执行：

```powershell
cd Y42_ESP32S3_Debugger
platformio run
platformio run --target upload --upload-port COM55
```

如果端口变化，在设备管理器中查找 `USB-Enhanced-SERIAL CH343` 对应端口并替换 `COM55`。

关键配置：

```text
主控：ESP32-S3 DevKitC-1 N8
调试串口：115200 baud
电机总线：115200 baud, 8N1
电机固件：X
```

## 手机连接

1. 给设备上电。
2. 手机连接开放热点 `Y42-Debug`，无需密码。
3. 系统一般会自动弹出测试页。
4. 没有自动弹出时，浏览器访问 `http://192.168.4.1/`。

固件固定使用 2.4 GHz 信道 1并关闭 Wi-Fi 省电。上电不会自动开始校准、轨迹或气泵动作。

## 电机布局和方向

```text
M1 左上       M2 右上


M4 左下       M3 右下
```

- M1、M3 朝自身角点收绳方向为 CW。
- M2、M4 朝自身角点收绳方向为 CCW。
- 电机安装、绕线方向或出绳位置改变后，必须重新确认 `PULL_DIRECTIONS`。

## 自动校准

校准前确认四根绳没有打结、叠绕或跨过错误线轮，球体能够在工作区内自由移动，并准备独立硬件急停。

网页参数：

- 框架边长：按实际机构填写。
- 小球直径：按实际球体填写；当前实物球直径约 80 mm。
- 目标电机电流：默认 1300 mA，可调至 2000 mA。
- 其余张紧电流：默认 225 mA。

固件依次让 M1、M2、M3、M4 把球拉向自身角点，记录四个角点处的四台编码器位置，再拟合 `deg/mm` 系数。只有四个角点全部通过且拟合质量合格，轨迹按钮才会执行。

校准过程会显示当前角点、目标电流、转速和四台电机遥测。电机不动时优先检查：

1. 地址是否为 1、2、3、4且没有重复。
2. 网页是否显示命令被电机接受。
3. A/B、共地和 115200 波特率是否正确。
4. `PULL_DIRECTIONS` 是否与实际绕线方向一致。
5. 其他三根绳是否把目标电机顶死。
6. 当前目标电流是否不足以克服静摩擦。

## 电流和安全保护

- 全流程硬超流上限：3000 mA。
- 目标校准电流输入上限：2000 mA。
- 过温停止阈值：55 摄氏度。
- 通讯中断、驱动器保护或堵转标志会停止自动流程。
- 原来非目标电机 500 mA 的误停条件已删除。

3000 mA 是软件保护上限，不代表机构应长期工作在 3000 mA。柔性底座、绳结或机械限位会使电流迅速上升。软件急停也不能代替切断动力电源的硬件急停。

## 轨迹控制

### 内置图形

- 圆形直径约占有效工作区的 80%，运行时间约 1.2 秒。
- 三角形约占有效工作区的 80% x 75%，运行时间约 0.9 秒。
- 移动到轨迹起点的速度上限为 400 RPM。

### 手绘轨迹

手机画布映射到整个已校准有效范围。固件会：

1. 删除小于 1 mm 的触摸抖动点。
2. 使用一次 Chaikin 圆角处理减少高速瞬间反向。
3. 删除旧版在尖角处人为插入的停顿。
4. 以约 143 Hz 发送四电机同步位置目标。
5. 将每个控制帧的最大空间位移限制为 3.5 mm。

速度框可以输入最高 5000 mm/s，但固件不会盲目照单执行。实际速度取以下限制的最小值：

- 当前四台电机校准系数换算出的 3000 RPM 极限。
- 143 Hz 控制周期下的连续性限制，当前约 500 mm/s。
- 轨迹总长度至少保留四个控制周期的限制。

网页会返回实际采用速度、电机极限速度和预计时间。高于约 500 mm/s 时，115200 baud RS485 无法为四台电机提供足够密集的位置点，表现会从轨迹变成跳点或抽动，因此固件优先保证连续性。

单次开放轨迹最终必须减速停车。首尾距离不超过 1 mm 的闭合轨迹使用“循环上次轨迹”时，可无停顿进入下一圈。

## 常见问题

### 手机没有自动打开页面

- 关闭手机移动数据后重新连接 `Y42-Debug`。
- 忘记旧的同名加密热点配置，再重新连接开放热点。
- 手动打开 `http://192.168.4.1/`。

### 一开始就显示超流

- 查看具体电机和实测电流，不要只提高阈值。
- 检查绳子是否已经拉到底、交叉或卡在线轮边缘。
- 检查电流回复是否使用 mA 单位。
- 当前固件只有超过 3000 mA 才判定软件超流。

### 高速轨迹抽动

- 重新刷新页面，确认返回信息中实际采用速度不超过连续性上限。
- 重新绘制，避免大量来回涂抹和自交尖角。
- 检查四台电机校准系数是否异常，某台系数过大会显著降低可用速度。
- 检查 115200 baud 总线是否存在丢包或地址冲突。

### 轨迹范围不够

- 当前圆和三角形已扩大到有效工作区约 80%。
- 手绘画布使用全有效范围。
- 检查校准时填写的框架边长和球体直径，以及保存的 `effectiveSideMm`。

## 已知边界

- 当前 RS485 波特率为 115200，四电机同步轨迹的稳定更新频率约 143 Hz。
- 开放热点适合现场调试，不适合暴露在公共环境中长期无人值守。
- 自动校准依赖正确的电机方向、绳路和地址，无法从软件中修复打结或错误绕线。
- 设备结构存在柔性变形时，校准系数会随张力变化，应使用一致的张紧电流重新校准。
