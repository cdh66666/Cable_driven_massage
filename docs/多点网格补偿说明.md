# 多点网格张力/绳路诊断与补偿

当前版本已具备串口采样结构，但地图只有在单层排线、固定导绳眼、固定偏航载架和 2+2 冗余闭合全部通过后才允许采集/启用；旧网格保持关闭。

## 网格定义

- 用户坐标系固定为球心工作区：`x=0..110mm`、`y=0..148mm`；卷轴轴心框为 198×148mm。
- 默认 `rows=7`、`cols=9`，共 63 个点；行沿 Y，列沿 X。
- 每一行交替反向，生成蛇形顺序；首尾点覆盖工作区边界，不额外扣除 40mm 球径。
- 行列可配置，但代码限制为低密度安全范围：行 `3..11`、列 `3..13`、总点数不超过 121。

## 节点数据

`grid_compensation.samples` 按 `row/col` 保存每个节点，包含：

- `absolute_positions_deg`：M1–M4 绝对编码器位置；
- `phase_current_ma`：M1–M4 相电流；
- `solved_xy_mm`、`solved_z_mm`、`z_fit_spread_mm`：四绳反解结果；
- `xy_error_mm`、`fit_error_mm`：相对网格目标点的误差和综合拟合误差；
- `tension_feedforward_ma`：以网格目标相电流（默认 120mA）减去各电机绝对相电流的有界前馈，正值表示需要增加电流余量；
- `position_compensation_deg`：`实测绝对位置 - 未修改的名义绝对位置`，表示将来加到目标位置的补偿量。

节点缺失、四电机字段不完整、无法反解、XY 误差超过 1mm、平面高度误差/四绳 Z 离散度超过 5mm、相电流低于 50mA 或拟合误差超过 5mm 时，节点 `valid=false` 并写入 `invalid_reason`。

## 插值和失效策略

`interpolate_grid_compensation()` 先检查版本、坐标系、110×148mm 边界和节点结构：

1. 查询点越界先夹紧到矩形内，并返回 `clamped=true`；
2. 四个包围节点都有效时使用双线性插值；
3. 任一包围节点缺失时，退化到最近有效点，返回 `method=nearest_valid`、`fallback=true` 和来源点距离；
4. 没有有效点或版本/结构错误时返回 `ok=false`；
5. 只有完整网格、显式 `enabled=true` 且全部机械/闭合门已通过时才允许实时使用；当前地图无效时绝对运动保持锁定，不退回未经验证的基础模型。

采样时不会根据相电流逐绳收放位置。Y42 的 0xCB 位置模式把电流字段作为上限；它不是四根绳各自可直接闭环的张力命令。边界上的正张力奇异点也不会再用人为权重下限伪装成可行点。

## 持久化

表格作为 `tools/y42_pc_calibration.json` 的 `grid_compensation` 子结构保存。重新做四角几何校准会丢弃旧网格并建立新的 `valid=false/enabled=false` 空表，避免旧基准污染新坐标系。

离线入口和测试位于：

- `tools/y42_pc_direct_web.py`：`grid_sampling_points()`、`build_grid_compensation()`、`interpolate_grid_compensation()`、`save_grid_compensation()`；
- `tools/test_y42_pc_offline.py`：网格边界、蛇形顺序、四电机字段、双线性/最近邻、版本拒绝和 JSON 持久化断言。
