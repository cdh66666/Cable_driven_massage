# Y42 手册与当前实机能力对照

依据：本机《ZDT Y42第二代闭环步进电机使用说明V1.1(1).pdf》（2025-06-13 V1.1），以及本项目 2026-09-06 实机归档。厂家声明与实测结论分开记录。

## 手册实际说明的能力

| 项目 | 手册内容 | 本项目解释 |
|---|---|---|
| 内部闭环 | 第7页：力矩环、速度环、位置环均标称20kHz | 不等于PC通过共享RS485每秒可完成20,000次四轴指令/查询；25Hz为当前诊断设定值 |
| 编码器 | 第7页：MT6816，14位 | 一圈量化间距360/16384≈0.021973°；分辨率不等于绝对精度 |
| 控制精度 | 第7页：标称小于0.08° | 未给本机构负载、速度、电源、温度等条件下的误差曲线；不能据此认定球心精度 |
| X位置反馈 | 第56页：0x36返回位置除10为角度 | 当前曲线量化间距0.1°；0.1°台阶不能单独证明真实机械抖动幅值 |
| 精细编码器接口 | 第53页：0x31线性化单圈值0..65535映射一圈 | 输出表示间距约0.005493°，不能把16位输出格式当成物理编码器有16位独立精度；跨圈需展开 |
| 误差接口 | 第57页：X的0x37位置误差除100 | 提供0.01°表示间距；可用于后续跟随误差记录，需核验目标量纲 |
| X目标输入 | 第40、64页：默认0.1°，可开0.01°输入 | 开启会改变所有位置指令的单位，必须同步编码、读回与测试；不可只改一个配置字节后沿用旧发送值 |
| 到位标志 | 第23、84页：默认到位窗口0.8° | 默认到位位不能作为0.08°精度验收；当前微幅验证另查原始反馈与停稳窗 |
| 多轴与通信 | 第24、35页：支持AA组合命令、同步触发；提示命令之间留几毫秒防粘包 | 手册没有给出四轴可靠闭环通信更新率保证；目前AA/CB未收到预期ACK，逐轴CB已完整通过 |
| 工作范围 | 第7页：10–29V，Y42驱动0–5A，转速0.1–3000RPM+ | 是驱动范围/标称，不是当前具体电机的额定扭矩曲线；当前电源读数约12V |

## 用12mm名义卷筒半径换算

以下仅为单根绳的理想弧长，不是球心位置误差：

- 0.1°对应约0.02094mm；0.08°对应约0.01676mm；0.8°对应约0.16755mm。
- 14位角量化间距对应约0.00460mm绳长。
- 单根绳若需50mm/s收放，卷筒约39.79RPM；当前1RPM诊断只相当于约1.257mm/s。
- 单根绳10N静态张力在12mm半径处需约0.12N·m轴扭矩，尚未计摩擦、加速度、卷绕半径变化及安全余量。

## 当前实测证明与局限

固定25Hz、0.5°逐轴往返、150mA位置电流上限、1RPM限速。`201647...df098109` 与 `201733...84a26bab` 在一次性写超时设置后连续完整通过，均148组指令，约24.998Hz，0跳帧、0超长间隔；停稳失能和原配置恢复均通过。

该结果证明当前条件下能完成受控四轴运动与反馈流程，不能证明额定负载、高速跟随、稳定张力、球心XY/Z精度或长期通信鲁棒性。150mA相对手册5A驱动上限仅3%，且CB是电流上限并非恒定输出电流，不能由这轮试验评价电机最大力矩。

两轮合并原始时间戳统计：单笔CB确认事务中位4.276ms，p95为5.014ms；两笔43反馈合计中位8.969ms；整组四笔CB加两笔43中位26.544ms，p95为28.719ms，最大30.319ms。四轴首发时差中位13.155ms，最大15.863ms；目前为明确记录时差的逐轴基线，并非四轴同时执行。指令周期中位40.001ms，对应设置的25Hz，未发现CPU算不动的证据。100Hz需要减少串行往返并核实组合命令的执行/应答证据，单改频率常量无法达到。

目前没有足够证据把问题归因为电机本体能力不足。已确认的系统问题包括主机收发调度、准备阶段串口超时重复设置、无效旧标定和未独立观测的绳路/球心位置。完整四角基准与实机绘图仍需完成。

该使用说明缺少当前具体电机的额定保持扭矩、力矩–转速曲线、负载下动态跟随误差及连续力矩温升曲线。评价最终按摩载荷能力必须补充这些数据或做受控负载实测。
