# 波特率对照与自动恢复修复

## 实机结果

- 上轮完整 0x48 电流写入对照（134019）：在 after_global_20 阶段，M3 转速回包 `03350000006b` 后附加 M1 错误 `0100ee6b`。未进入轨迹运动；归档确认 motion_observed=false、final_disabled_confirmed=true、configuration_restored=true。更换电流写入指令没有解决错误，已恢复短 0x45。
- 本轮从 921600 改至手册支持的 512000，四台写入 ACK 成功，新速率完整配置校验失败。静止扫描出现随机损坏：一次 M1 `8127a0ed`，另一次 M3 `033a82ed`；其余轴返回正常状态。该速率未通过静止通信验证，未执行微动。
- 原批量恢复在 STOP/DISABLE 全部 ACK 门槛处失败，尚未写配置。随后按轴确认 512000 下状态精确为 `id 3a 02 6b`，从本轮写入前的完整配置恢复 921600，并逐轴核对完整 37 字节配置相等。四轴恢复通过。
- 最终主动状态查询：四台在线、RPM=0、flags=2；位置依次为 9.5、137.8、-57.7、-1065.6°。随后锁定控制按钮。

## 修复

新增 `tools/y42_baud_recovery.py`，接入 `set_all_motor_baud` 的新速率验证失败分支。保留原配置快照，按轴确认失能后恢复原配置；写入 ACK 不作为恢复成功依据，必须原速率下完整配置相等且状态确认失能。恢复结果和原始收发逐笔记录。任何不完整恢复仍锁定控制，不自动恢复运动。

测试覆盖：写入 ACK 丢失但完整回读成功、使能状态禁止写入、其他配置字段被改变必须失败、快照无效禁止访问总线。4 项通过，相关 Python 文件编译通过。
