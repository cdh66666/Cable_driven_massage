## 本次确认的软件缺陷与修正

1. 自动准备会把错误状态覆盖成 idle。增加 `last_failure`（失败标识、run_id、原因、发生时间），独立于当前连接状态；页面弹窗并常驻提示最近一次未完成。
2. 手绘入口把布尔函数 `active_auto()` 和字符串比较，运行中判断永远为假。修正判断，并与自动任务共用请求锁，拒绝重叠控制请求。
3. 起点到位等待只读取位置、转速和状态，电流/温度来自动作之前的缓存。增加可选实时负载查询，起点每次检查读取当前相电流及温度，缺失时停止；相电流不是直接绳张力。
4. 平滑起点最后一帧重发前增加急停检查，避免等待期间收到急停却再发终点。
5. 去掉没有实测保证的“通常约 15 秒”启动文案，实际耗时以 run 为准。
6. 新增坏曲线物理门禁：当前四角模型任一段隐含卷径超过 CAD 外缘半径 20 mm 即拒绝。前向、反向、模型准入、校准发布均检查；不通过时不得悄悄退回旧线性模型或角点补偿。原始标定参数和原始 run 不删除。

## 为什么不能把当前叠图称为高精度

冻结本次校准后，同一 M1–M3 目标长度有至少两组平面位姿解：

| 解 | x / mm | y / mm | yaw / ° |
|---|---:|---:|---:|
| 指令解 | 22.000 | 29.600 | 0.000 |
| 另一装配分支 | 27.631 | 29.234 | −25.793 |

第二组需要的 M4 绳长比目标多约 5.507 mm。失败时四轴模型反算约 `(28.86, 29.78, −30.39°)`，闭合 RMS 仅约 0.134 mm，但其模型 XY 距目标仍约 6.865 mm。**小闭合残差既不是到位证明，更不是独立物理精度。**

旧程序把四角观测直接连成分段曲线；M4 一段 126.7478→137.5497 mm 对应仅 153.15→153.30°，斜率约 0.013886°/mm。若解释成卷径，相当于约 4126 mm 半径，明显不是名义 12 mm 卷筒的真实排线。仅检查单调性和全局 R² 不够。

单一全局线性模型也不能自动消除问题：旧几何下四轴角点残差（折算为绳长而非 XY 真误差）RMS 约 2.09 / 2.83 / 3.16 / 3.84 mm；最大约 3.10 / 4.72 / 4.62 / 5.72 mm。不能把 R² 为 0.996–0.999 写成亚毫米精度。

## 离线候选（未据此宣称实机通过）

- `y42_bounded_spool_model.py`：带显式物理范围与残差检查的单一仿射模型；原始四角样本保留，拒绝超界拟合，不夹紧系数伪装合格。生成的运行节点明确标为拟合节点而非新观测。
- `y42_spool_geometry.py`：圆柱切点 + 包角变化的完整平面放绳模型，不仅计算自由直线段。模型仍不能观测轴向乱绕、叠层、滑移或球的滚转/俯仰。
- 新圆柱模型已通过切点正交、包角导数、跨 ±π 连续性及平面位姿 Jacobian 有限差分测试；数学自洽不代表该现场绕绳分支和半径已经实测验证。

实际离线对比结果否决了直接上线：照片候选绕线分支 `+−+−` 加完整包角后，四轴角点 affine 残差 RMS 为 4.44 / 5.14 / 5.58 / 6.30 mm，比旧几何 affine 更大；反向分支也更差。候选只保留在离线模块，没有让它控制实机。

又检验了“不指定四角 XY，只用全程冗余闭合”的自校准替代方案：正确分割合法前缀遥测后，980 条事件中有 28 轮完整四轴反馈，而非 980 个位姿。16 轮静止反馈仅形成 6 个独立姿态簇；每姿态最多约束一个消去 XY/yaw 后的闭合量，对 4 斜率 + 4 零偏共 8 个未知量，静态数据的秩最多为 6。动态四轴位置采样时差 318–433 ms，不能当同步观测使用。

20 样本、3 初值的离线 bundle 拟合 RMS 约 0.989–1.057 mm，最大残差 2.94–4.19 mm，不同初值仍给出明显不同卷径；这不是实测绝对精度或可部署的参数。复算脚本为 `tools/analyze_y42_bundle_offline.py`。本批数据不足以替代可靠的位置基准或同步、多姿态、持续张紧的辨识采样。

绕轮模型需要同时考虑切点和包角，与原始研究 [Cable-driven parallel robot modelling considering pulley kinematics and cable elasticity](https://www.sciencedirect.com/science/article/pii/S0094114X21000215) 的问题范围相符；不能把通用论文模型或其他开源机器的参数直接当本机标定结果。相关四索开源运动学实现：[CDPR_4cables_kinematics_library](https://github.com/laboratoriorma3/CDPR_4cables_kinematics_library)。
