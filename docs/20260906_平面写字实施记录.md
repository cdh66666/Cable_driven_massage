# 平面写字：模型、时序与验收

用户已同意先做接触平面的 XY 写字，再处理抬笔/张力。保留原始手绘折线，不平滑、不切角；已有标定资料保留，不把未知参数写成已验证。

## 验收顺序

1. 原始点 → 同一个几何/补偿映射 → 电机目标角度 → 实际协议量化 → 同一个映射的数值反解。保留原始目标、编码后的目标和反算点，单独统计软件往返误差。
2. 纯几何预测与动力学仿真共用卷筒切点/包角公式。名义半径、固定出绳高度、绕向仍属于假设；不能直接迁移旧标定截距来驱动实机。
3. 同一周期更新四轴目标。标定/起终点等待反馈连续稳定；连续画线按时间戳对齐目标与反馈，不在每个插值点等待停稳。
4. 每条原始边只改变时间参数。规划节点对齐实际控制周期；加密点不改变原始拐点。
5. 电机反馈反算不等于独立小球实测。实机验收保留原始帧、目标帧、时间戳、反馈反算图及实际笔迹证据；缺失部分不补画。

## 发现的问题

- 控制代码的名义固定出口模型与仿真的圆柱切线/包角模型不同。
- 目标侧可能包含四角和网格补偿，而单纯角度转基础绳长再做固定锚点反解无法自动撤销这些补偿。应对完整目标映射求逆。
- 相对高度原公式 `sqrt(current_z_squared - baseline_z_squared)` 忽略原本存在的竖直间距。固定水平位置理想关系是 `delta = 2*h0*lift + lift^2`。未知实际基准不能伪装成已测毫米高度。
- 接近平面时高度对绳长误差敏感。当前写字不使用未知高度去修正 XY；电流上限也不作为恒定张力实测值。

## 本轮修改与检查

- `plan_custom_motion_segments` 增加明确的 `control_tick_s`，主调用传入实际配置周期；不再把路径节点时钟硬编码为 100 Hz。
- `sample_cumulative_path` 同时检查区间两端的浮点命中，避免恰到拐点的数值略超边界时丢失原始点。
- `exact_vertex_profile` 拒绝非有限参数和非有限路径。
- 原始折线测试 7 项、运动分段测试 10 项通过，含 25 Hz 与 100 Hz 节点保留、路径长度和运动限值。

以上为源代码和离线验收；不代表运行中的旧控制器已加载，也不代表已完成本轮实机写字。

## 完成本轮集成

- 主控制器源代码的轨迹基线改为 25 Hz，规划传入 40 ms 周期。旧运行进程尚未加载此修改。
- 新增 `motor_targets_to_xy` 对完整 `grid_motor_positions_at` 映射求逆，包含四角和网格补偿。分别报告数值收敛与真实标定有效性；没有篡改原校准 `valid=false`。
- 仿真的几何函数调用共享固定高度圆柱模型。仿真以 2 ms 积分，但电机目标每 40 ms 更新，加入 0.1° 角度量化，其间保持上一次目标。
- 高度修正按每根绳的已知初始高度差反解；未知初始高度差时不发布毫米高度。有已知基准时，范围和一致性检查使用反解后的实际高度；不可能的负开方项拒绝。
- 8788 独立仿真服务已经更新，增加纯模型文件的 SHA256 版本热加载。一次启动遇到环境缺少 scipy，已使用具备依赖的 `D:\codex\.cad_env\Scripts\python.exe` 恢复。后续模型源文件变化已经通过 HTTP 验证自动加载，无需重启。
- 串口控制器 8787 没有重启、没有替换，也没有执行新的实机动作。此前针对旧串口控制器的终止操作被策略拒绝；本轮没有重试该操作或绕过它。
