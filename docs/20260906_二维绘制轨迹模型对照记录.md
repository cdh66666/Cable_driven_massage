# 二维绘制轨迹模型对照记录

本记录对应 `qa/twin/drawing-comparison.png`、`drawing-comparison-input.json` 和 `drawing-comparison-output.json`。图和 JSON 均为离线模型预览，明确标注“模型非实测”；本轮没有打开串口、访问 HTTP 或向控制器发送指令。

## 方法

- 绘图脚本：`tools/plot_y42_drawing_comparison.py`。
- 直接调用现有 `tools/y42_twin_model.py` 的 `preset()` 与 `simulate()`，没有修改模型或控制器。
- 对圆形、方框、蛇形和确定性的手绘样式闭合曲线，保留原始 XYZ 输入点；分别用 `spacing=1.0 mm`（粗采样）和 `spacing=0.25 mm`（细采样）调用 `simulate()`。
- 图中黑线是绘制原线（输入），橙线和蓝线是模型 `pose` 的二维 XY 路径。四个子图和页脚均说明结果不是实测。
- 形状保真指标是每个仿真 pose 点到原始输入折线的最短 XY 距离，输出 RMS、P95 和最大值；它描述当前简化模型相对输入线的偏离，不是控制器或设备精度证明。

## 复核边界

已用生成的 PNG 做视觉检查：四类轨迹均落在模型预览范围内，原线、粗采样仿真和细采样仿真可区分，中文标题/图例和“模型非实测”提示可读。当前结果只验证离线绘图链路和给定简化模型的可重复输出；不覆盖实机反馈、100 Hz 控制写入、物理参数辨识或通信正确性。
