# 先调通功能，再测试上限

用户要求：完整保留手绘节点，不平滑；先完成通信、四角校准、绘图、蛇形高度的完整流程，再优化速度与鲁棒性。使用真实硬件几何与已有代码，保留每轮原始轨迹和前后对比图。四角校准负责建立状态，不额外要求摆中心。

## 执行顺序

1. 25 Hz 主机独占收发，逐轴明确确认，四轴半度往返完整运行并重复验证。记录实际指令、原始编码器、轴间时差、反馈年龄、异常与收尾。
2. 四角校准：确认机构实际角点约束，修复受控到角与停稳采样，保留已有拟合质量检查。四角力矢量静止不能直接替代角点身份。
3. 低速完整手绘轨迹：按原始折线细分，所有原始节点按顺序到达，比较目标、仿真和编码器反解 XY；不把反解位置标为独立球心测量。
4. 蛇形路径和高度：使用可核验高度基准/反馈，区分模型预计高度与真实测量；保留同一路径逐轮图。
5. 基线通过后提高频率、速度、点密度；明确每个级别的实际完成率、误差、延迟和停止原因。

25 Hz 是当前 COMMAND_HZ 人工设定值，不是电脑计算能力测量。现行事务安排每组需要四个 CB ACK 和两个 43 完整反馈；高频优化应减少串行往返、明确设备应答契约，不能靠放宽期限或删除坏帧。原始手绘节点保留策略不随控制频率改变：保持形状时需要相应调整行进速度。

## 更新规则

微幅适配器按 SHA 在新 worker 加载，执行中的 worker 不替换代码。纯探测核心随适配器加载版本。前端 HTML 刷新生效。其他后台改动必须核实部署范围，不能将适配器热加载说成整个程序热更新。
